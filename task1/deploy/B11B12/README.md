# B11 / B12 배포 세트 — FSR 저해상도 대응 (팁당 1값)

실물 fingertip FSR 의 **공간 해상도가 sim 6존 기하에 못 미치는 문제**에 대응해,
존 분해를 버리고 **손가락당 1값**으로 학습한 두 모델이다. 기구·배치·상수는 B08 세트와 동일하다
(캡 0.250 · 마운트 32mm · 텀블러 몸체 228mm · 지그 오차 ±2mm 학습 · 마찰 커리큘럼 종점 **2.5**).

| 모델 | FSR 힘 해상도 | 실물이 읽어야 하는 것 |
|---|---|---|
| B11 | 10단계 (기존 경계표) | 팁당 힘 [N] — 캘리브레이션 필요 |
| **B12** | **2단계 (binary)** | **팁당 "≥1N 접촉 여부" 1비트 — 캘리브레이션 최소** |

## ★ FSR 채널 조립 방식 (반드시 이대로)

관측 벡터의 `cap_tip_force6` 24채널(`target[41:65]`) 형식은 기존과 같다:
**인덱스 = 41 + 6×손가락 + 존**, 손가락 순서 [0]엄지 [1]검지 [2]중지 [3]약지, 존 6개.

달라진 것은 **채우는 값**이다 — 존별 값이 아니라 **팁당 1값을 그 손가락의 6칸 전부에 복제**한다.

### B11 (10단계) 조립 절차

```python
# 손가락 f 마다 (60Hz 매 스텝):
F = sum(그 팁의 모든 FSR 셀이 읽은 수직력 [N])   # 패드 위 셀 전부의 합. 셀 수 무관
ema[f] += 0.3 * (F - ema[f])                     # EMA (에피소드 시작 시 0)
edges = [1, 2, 3.5, 5, 6.5, 8.5, 11, 15, 21]
lvl   = sum(1 for e in edges if e < ema[f])      # 0~9 (경계값과 같으면 아래 칸)
obs[41+6*f : 41+6*f+6] = lvl / 9.0               # ★ 6칸 전부 같은 값
```

### B12 (binary) 조립 절차

```python
F = sum(그 팁의 모든 FSR 셀 수직력 [N])
ema[f] += 0.3 * (F - ema[f])
lvl   = 1 if ema[f] > 1.0 else 0                 # 경계 1N 하나뿐
obs[41+6*f : 41+6*f+6] = lvl / 9.0               # ★ 0.0 또는 0.1111... 을 6칸 복제
```

주의:
- **B12 의 접촉값은 1.0 이 아니라 1/9 = 0.1111 이다** (학습이 10단계 격자의 레벨 1 로 봤기 때문).
- EMA 는 **팁당 1개**만 유지한다(24개 아님). α=0.3 은 60Hz 기준 — 루프 주파수가 다르면 재계산.
- 존 위치·귀속·힘 분배는 일절 필요 없다. 패드 위 셀이 몇 개든 **합쳐서 1값**이면 된다.
- 패드 밖 접촉(팁 옆면·모서리)은 학습에서도 0 이었다 — 실물 FSR 가 못 읽어도 정합.

- **전체 추천은 `b12_policy_ep9000.pth`** — 전 조건 견고 + 실물 FSR 요구 최소(1비트).
- B11 을 쓴다면 **ep4000**(마찰 2.5 도달 ep2782 + ~1200ep 연마 시점)을 쓸 것.
  ep6000 부터 쉬운 조건이 무너진다(1/12 → ep9000 0/11) — 학습 조건 과적합이 진행되는
  전형적 패턴으로, "커리큘럼 완료 직후 체크포인트가 조건 변화에 강건"(B02 교훈)이 재확인됐다.
- 힘 해상도 결론: **10단계가 binary 보다 나은 조건이 하나도 없었다.**

## B12 조건 내성 그리드 (ep9000, 신선 env 결정론, 조건당 10~12 에피소드)

| 나사 저항 | μ5.0 | μ3.0 | μ2.5 | μ2.0 | μ1.5 |
|---|---|---|---|---|---|
| 0.2 N·m | 11/11 | | | | |
| 2.0 N·m | 12/12 | | | | |
| 4.0 N·m | 12/12 | 12/12 | 10/11 | **8/12** | **0/10** |
| 6.0 N·m | 12/12 | | | | |
| **8.0 N·m** | **12/12** | | **11/12** | | |

- **저항축은 사실상 무제한** — 학습 상한(4.0)의 2배인 8.0N·m 에서도 12/12, 저항 8.0+μ2.5 조합도 11/12.
  J롤(팔 토크)이 돌리므로 나사 저항은 병목이 아니다(계보 공통 성질).
- **마찰축이 하한을 정한다**: μ2.5(학습 종점)까지 견고, μ2.0 은 8/12 로 강하락, **μ1.5 는 0/10**.
  학습 종점(2.5) 밖으로는 반 계단(0.5) 만에 무너진다 — 실물 실리콘 팁 마찰이 2.5 미만으로
  의심되면 0.1σ 액션 디더링을 켜거나, 마찰 종점을 낮춘 재학습이 필요하다.
- J6 롤 +176~194° 로 전 조건 일관 — binary 관측에서도 스타일이 흔들리지 않는다.
