## 한계 — 반드시 알고 쓸 것

1. **마찰 커리큘럼 미시작.** 학습 내내 μ5.0 이었다. 저마찰 성능 미검증 — 0.1σ 액션 디더링 필수.
2. **성능 미측정.** 사용자 지시로 이번 세트는 평가 없이 구성했다. 신선 env 완주율 데이터가 없다.
3. **`wrist_pos_ref` 미검증.** z 는 sim 실측이 아니라 기존 두 실측점에서 유도했다
   (`ref_z = 2.0·cap_z − 0.09893`, 두 점이 정확히 일치). **배포 전 `CAP_DEMO_WRIST_PRINT=1` 로 재확인할 것.**
4. **회전 방식이 손끝 미끄러짐 위주다.** J6 기여 17%(정본 106%), 역슬립 6.0mm.
   실리콘 팁 마모·표면 상태에 민감할 수 있다.
