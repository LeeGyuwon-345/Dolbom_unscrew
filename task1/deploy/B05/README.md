# B05 배포 세트 — 텀블러 22mm 배치

학습 run `B05_20260902_131345` (B04 ep2500 웜스타트). 구현 스펙은 **[DEPLOY_B05.md](DEPLOY_B05.md)** 하나만 보면 된다.

## 무엇이 다른가 (B02 세트 대비)

| 항목 | B02 | **B05** |
|---|---|---|
| 텀블러 바닥 (RB5 베이스 기준) | +31mm | **+22mm** |
| 캡 중심 z | 0.246 | **0.237** |
| 지그 오차 학습 | 없음 | **±2mm 노이즈 포함** |
| 4지 접촉(회전 중 압착률) | 검지 3% · 약지 7% | **검지 99% · 약지 95%** |
| 회전 방식 | J롤 (J6 +150~210°) | 손끝 미끄러짐 위주 (J6 +64~72°) |
| 마찰 학습 범위 | 5.0 → **2.0** | 5.0 만 |

**지그 오차 ±2mm 를 학습에 넣은 첫 세트**다. 매 리셋마다 텀블러가 ±2mm 움직이는데
관측 기준은 공칭 위치로 고정했으므로, 로봇 PC 가 지그 좌표를 상수로 쓰는 실제 상황과 같다.

## 한계 — 반드시 알고 쓸 것

1. **마찰 커리큘럼 미시작.** 학습 내내 μ5.0 이었다. μ2.0 에서 4/6 은 기대 이상이나
   B02(11/11)에 못 미친다. 저마찰이 의심되면 0.1σ 액션 디더링 필수.
2. **미끄러뜨려 여는 방식.** 손목 기여가 약 40% 뿐이고 나머지는 팁이 캡 표면을 미끄러진다
   (팁 슬립 22.7mm, B02 는 11.9mm). 실리콘 팁 마모·표면 상태에 더 민감할 수 있다.
3. **중간 체크포인트다.** 20000ep 중 ep1200 에서 중지했다(저항 3.3/4.0N·m).
