# FSR 보정용 기록 — `b05_fsr_calibration_episode.csv`

B05 정책(`b05_policy_ep1200.pth`)이 캡을 **180° 완주한 성공 에피소드 1회**(359스텝, 60Hz = 약 6초)의
FSR 파이프라인 **전 단계**를 그대로 남긴 것이다. 실물 FSR 을 sim 과 같은 값으로 만들 때 대조표로 쓴다.

측정 조건: 나사 저항 3.3N·m, 마찰 μ5.0, 텀블러 22mm 배치, 지그 노이즈 off.

## 컬럼 (총 78)

| 구간 | 컬럼 | 내용 |
|---|---|---|
| 1 | `step` | 0~358 (60Hz) |
| 2 | `cap_deg` | 그 시점 캡 풀림각 [deg] |
| 3~26 | `raw_*` (24) | **① 존별 원시 수직힘 [N]** — 필터 전 |
| 27~50 | `filt_*` (24) | **② EMA 저역통과 후 [N]** — `ema += 0.3*(F-ema)` |
| 51~74 | `lvl_*` (24) | **③ 양자화 레벨 0~9** |
| 75~78 | `tot_*` (4) | 팁 몸체 전체의 패드법선 힘 [N] (참고용) |

정책이 실제로 받는 관측값은 **`lvl / 9`** 다 (0.000, 0.111, …, 1.000).

## 존 이름 규칙

`{손가락}_{위치}_{원위/근위}` — 손가락 **th**(엄지) **ix**(검지) **mi**(중지) **ri**(약지),
위치 **c**(중앙) **ny**(−y) **py**(+y), **d**(원위, 손톱쪽) **p**(근위, 손가락 안쪽).
관측 벡터 순서와 동일하다: `target[41:65]` = `41 + 6×손가락 + 존`.

## 재현해야 하는 파이프라인 (실물 FSR)

```python
# ① 각 존의 수직 압력을 뉴턴으로 환산   <- 여기가 보정 대상
F = calibrate(adc_reading)

# ② EMA 저역통과 (60Hz, α=0.3, 에피소드 시작 시 0)
ema = ema + 0.3 * (F - ema)

# ③ 양자화: 레벨 = 경계값 중 ema 보다 작은 것의 개수
edges = [1, 2, 3.5, 5, 6.5, 8.5, 11, 15, 21]      # N
lvl   = sum(1 for e in edges if e < ema)           # 0~9
obs   = lvl / 9
```

`raw_*` → `filt_*` → `lvl_*` 세 컬럼이 위 ①②③ 각 단계의 정답이다.
자기 구현에 `raw_*` 를 넣었을 때 `filt_*`·`lvl_*` 가 재현되는지 먼저 확인하면 ②③ 을 검증할 수 있고,
그 다음 실물 센서로 ① 을 맞추면 된다.

## 이 에피소드의 힘 분포 (보정 범위 잡기용)

0 이 아닌 값만 집계한 존별 원시힘 [N]:

| 존 | 중앙 | 최대 | | 존 | 중앙 | 최대 |
|---|---|---|---|---|---|---|
| th_ny_d | 1.87 | 4.69 | | mi_py_d | 1.20 | 11.47 |
| th_ny_p | 0.90 | 13.43 | | mi_py_p | 0.72 | **47.01** |
| th_py_p | 0.49 | 22.46 | | mi_ny_p | 0.51 | 25.03 |
| ix_c_d | 1.20 | 7.99 | | ri_c_p | 0.83 | **66.31** |
| ix_ny_p | 0.01 | 10.20 | | ri_py_p | 1.33 | 23.03 |

- **상시 쓰이는 대역은 0~5N** 이다. 이 구간의 해상도가 가장 중요하다(경계 1/2/3.5/5 가 몰려 있다).
- 충돌 순간에 **20~66N** 스파이크가 난다. 센서 포화가 이 값 아래면 레벨 9 로 뭉개진다 — 허용된다
  (양자화 상한이 21N 이라 그 위는 어차피 같은 레벨).
- `ri_ny_*` 는 이 에피소드에서 한 번도 안 눌렸다(약지가 그 방향으로 캡을 안 만짐). 보정은 필요하나
  이 데이터로는 검증할 수 없다.

## 주의

- **α=0.3 은 60Hz 기준**이다. 실물 루프가 다른 주파수면 컷오프(~4Hz)가 맞도록 α 를 다시 계산할 것.
- 에피소드 시작 시 EMA 를 **0 으로 초기화**해야 첫 스텝이 일치한다.
- 이 기록은 **sim 접촉력**이다. 실물 실리콘 팁의 접촉 면적·변형이 다르면 같은 파지에서도 값이
  다를 수 있다. 목표는 "같은 파지에서 같은 레벨이 나오게" 맞추는 것이지 N 값 자체의 일치가 아니다.
