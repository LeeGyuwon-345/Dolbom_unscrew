# B08 배포 세트 — 신 기구(마운트 32mm) · 신 텀블러(몸체 228mm)

학습 run `B08_20260902_231948`. **정본(B02)과 보상·관측이 동일**하고, 기구/배치만 실측 반영한
첫 세트다. 여기에 검증된 2변수(저항 계단 0.3, 지그 노이즈 ±2mm)만 추가했다.

## 기구·배치

| 항목 | 값 |
|---|---|
| 로봇 URDF | `hand_mount y=-0.0615` — RB5 마운트면–손등 **32.0mm** |
| 텀블러 몸체 | **228mm** |
| 텀블러 바닥 | (0.400, 0.000, **0.022**) |
| `cap_home` (캡 원점) | (0.400, 0.000, **0.250**) — 캡 상면 0.266 |
| `wrist_pos_ref` | (0.38492, −0.01295, **0.38807**) — **sim 실측** |
| 지그 오차 학습 | ±2mm |

> ⚠️ `wrist_pos_ref` 는 캡 높이뿐 아니라 **로봇 URDF(hand_mount)에도 의존**한다.
> 샘플러가 손 기구를 포함해 도달 가능한 손목 자세를 뽑기 때문이다.
> 실측점: 캡0.250+마운트32mm → **0.38807** / 캡0.246+마운트30.5mm → 0.39307 / 캡0.237+마운트30.5mm → 0.37507.
> 둘 중 하나라도 바뀌면 `CAP_DEMO_WRIST_PRINT=1` 로 **재측정 필수**(외삽하면 10mm 이상 틀린다).

## 체크포인트 — B10 정책 포함

**B10 run(`B10_20260903_154810`)의 정책이 이 세트와 완전 호환된다.** B10 = B08 + z 슬립
과금 2변수인데 둘 다 보상 항이라 관측·네트워크·기구·상수·시작자세가 전부 동일하다.
상수/자세/덤프는 이 폴더 것을 그대로 쓰고 `.pth` 만 바꾸면 된다.

- B10 의 마찰 2.0 전이 붕괴는 미미했다(최저 sr 0.888) — B02(0.185)·B08(0.185)과 대조적.
- ⚠️ **정규화 통계(RunningMeanStd)는 각 `.pth` 안에 있다.** 정책과 통계를 반드시 같은
  파일에서 로드할 것. B08 상수로 B10 정책을 돌리는 것은 되지만, 통계를 섞으면 안 된다.
- B10 에만 있는 z 슬립 과금은 학습 전용이라 배포에 영향 없다(실측 z 슬립 5.5mm 로
  B08 의 4.8mm 와 사실상 동일 — 억제 효과는 없었고 성능 손실도 없었다).

## 검증된 것 (이번 run 의 성과)

- **저항 계단 0.3 은 무죄** — 저항 구간 내내 sr 0.96~0.99, 4.0N·m 도달이 정본 대비 **1,600 epoch 빠름**
- **지그 노이즈 ±2mm 는 형성을 막지 않음** — 재추첨 0회(정본은 1회)
- z 슬립 4.8mm 로 정본(6.5mm)보다 작음

## 한계

1. ep20000 은 5조건 스윕 완료. B02 최종본이 겪던 '쉬운 조건 퇴화'가 없다(0.2N·m/μ5 에서 11/11).
2. 학습 조건(4.0/μ2.0)만은 ep8500(8/8)이 ep20000(8/11)보다 나았다 — 실물 마찰이 확실히 2.0 근처라면 ep8500 고려.
3. 저마찰 실물이 의심되면 0.1σ 액션 디더링 권장(§B05 문서 5-1 참조).
