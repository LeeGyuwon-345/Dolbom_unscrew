- 제어 60Hz, 에피소드 360스텝(6초), 액션 22(팔6+손16) 절대 관절각 목표로 적분
- DOF 순서 **검지→엄지→중지→약지** (URDF 파일 순서와 다름)
- 관측 정규화(RunningMeanStd)는 체크포인트에서 로드해 키별 적용
- **A95는 낮은 마찰에서 0.1σ 액션 디더링 필수** (문서 §5-1). B02 는 결정론으로 동작하나 시운전 초기엔 권장
- ⚠️ **배치가 다르면 상수도 다르다**: `wrist_pos_ref` z 는 31mm 세트 0.39307 / **22mm 세트(B05) 0.37507**.
