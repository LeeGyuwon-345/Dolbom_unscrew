# RB5-850E + Allegro 캡 unscrew — A 시리즈 런 히스토리

RB5 팔 + Allegro 손(vmount) 통합 학습의 전체 계보. 모든 런의 공통 뼈대는
ManipTrans `ObjDexUnscrew` (trajectory-free, PHASE_DIM=0), vmount URDF,
초기 파지 `arm_grasp_init_closed_vmount.json`, 512 env, PPO.
자세한 회차별 수치·프로브 기록은 세션 로그와 `allegro-migration` 메모 참조.

## 범용 교훈 (재발 방지)

1. **판정은 신선 env 재생으로** — 라이브 학습 sr은 env 결함·이력 오염을 반영할 수 있다 (A14/A15b 사태).

3. **스크래치 부트스트랩 보호**: 페널티류(에너지 등)는 성공률 램프 뒤에, 고난도(고저항·다차원 랜덤화)는 커리큘럼/웜스타트로.

5. **침체 진단**: 분포 프로브 + 에피소드 내 시계열을 함께 볼 것 (시간 한계 vs 행동 정체 판별).
6. **kill 후 pgrep 확인** (좀비 GPU 공유), pkill 패턴 자기-매칭 주의.
7. **웜스타트 체인 관리**: 재시작 과도의 깊이는 체인 깊이 × 베이스의 장수 env 적응도에 비례 (A25→A26→A26b에서 실측). 신선 env PLAY가 정상이어도 훈련 재개가 죽을 수 있다. 재개 베이스는 가장 얕은 "검증된" 체크포인트로.
8. **정체 원인 3분법**: 각도 덤프로 판별 — ①0° 근처 정체=부트스트랩 단절(→커리큘럼), ②중간각 균일 정체+드랍 없음=시간 한계(→스텝 연장 or 분포 조정), ③μ별 양극화=랜덤화 과부하(→웜스타트 분해). A27/A26/A20이 각각의 표본.
9. **라이브 sr은 게이트일 뿐**: 전진 판정은 반드시 신선 env 재생 그리드(분포+최악 코너)로. A26에서 라이브 0.999 vs 신선 76% 괴리 실측.
10. **숨은 DR 확인**: `ObjDexUnscrew.yaml`의 `randomize: ${if:test,False,True}` — 훈련만 캡 마찰 ×3 (PhysX 재질 고착으로 사실상 영구) + 무중력 시작. 신규 run은 randomize=False + 마찰 명시가 표준 (A37~). 구 체크포인트 재생 시 randomize=True 필요 여부는 **계보의 강건성에 달림** (실측: A30은 DR 없이 해제 99.7% — 오히려 DR-on이 91%로 약간 불리; A35는 DR-on이어야 12.7% 회복). 취약 계보만 필수.
11. **온라인 공적응 갭**: 라이브 sr은 "정책이 자기 데이터 분포와 함께 움직이며 내는 성적" — 동결+신선과 수십 %p 벌어질 수 있다 (A35: 80% vs 13.6%). 갭 크기 = 정책 취약성 지표. 관측 풍족 계보(A16c/A30/A23b)는 갭 없음(96~100%).
12. **잔차 브레이크 페달 금지**: 외부 어시스트(J6 등)에 정책 잔차가 감속 권한을 가지면 "위험 회피" 그래디언트가 항상 이긴다 (A32/A32b/A33 3연속 실측). 발견은 어시스트가 아니라 스칼라 커리큘럼의 "궁핍의 창"으로 (A35).
13. **재생 env 복제는 런처 입력변수로**: 학습 프로세스 `/proc/PID/environ`이 근거. CAP_* 출력값 직접 전달은 런처 기본값에 덮인다 (마운트 소실·텀블러 위치 오류 사고 2건). 전용 재생 래퍼(play_a38.sh)를 run마다 유지할 것.

## 슬립(비비기) 측정 방법론 (2026-08-24 확립)

도구: `slip.py`/`slip2.py`/`slip3.py`/`slip4.py` (CSV 관절궤적 → Isaac Gym FK
재생), env 내장 `CAP_SLIP_DEBUG=N` (드리프트·계수·벌점·접촉팁수·앵커리셋 +
dead 후보 6개 동시 스윕).

**네 정책의 비비기 유형 분해**:

| run | 전략 | J6 스윕 | 접촉 형태 | 단방향 드리프트 |
|---|---|---|---|---|
| A51 | 롤 | 179° | 길게 잡고 버팀 | **팁이 캡보다 40~60° 앞섬** (파지력 부족 → 전방 미끄럼) |
| A52L | 임펄스 | 94° | 중간 | 20~26° |
| A53 | 롤+채터 | 175° | 짧게 자주 | 14~20° (채터로 접촉 깜빡임) |
| A54 | 스와이프 | 15° | 한 번 잡고 유지(352스텝) | **125~141°** (제자리 문지름) |

## A55 (슬립 페널티 단일 변수 ablation, 2026-08-24 기동)

구성 = **A54 + 슬립 페널티만** (초기자세 노이즈 없음 — 효과 분리를 위해

**벌점 정식화**: 접촉 시작 후 캡 프레임 이탈 누적각 `drift` 에 대해
`w · kc · mean_{접촉팁} clamp((|drift| − dead)/ref, 0, 1)`. 누적 방식이라
180° 초과도 안전(앵커 비교식의 감김 문제 회피), 접촉이 끊기면 0 리셋 →
**재파지 자체는 무료**(정당한 게이팅·회복을 벌하지 않음). dead 20° =
r44 에서 15mm ≈ 실리콘 팁 패드(10.6×12.6mm) 한 장 길이.

**사전 검증 예측치** (실제 env, kc≈0.49): A54형 문지름 계수 0.344(스텝당
−0.69) vs A53형 0.046(−0.09) — 판별력 7.5배.

**판정 기준** (사전 합의): ep1500 시점 **J6 스윕 ≥ 60° → 성공**(슬립 항만으로
롤 유도), **< 30° → 무력**(비비기만 막음) → 직접 유도 수단 추가(롤 크레딧
재도입 또는 손 액션 스케일 축소).
